好吧好吧，既然你这么想看，那我就勉为其难地介绍一下这个叫做 **Fob** 的小东西。  
它是个操作系统内核，不过别指望它能干正事，它就是个玩具，用来在 QEMU 里卖萌的。

## 它能干什么？

- 开机后给你一个 `>` 提示符，你可以输入一些命令，比如 `help`、`fortune`、`calc`、`meminfo`。
- 支持 Shift 键和 Caps Lock，所以你可以输入大写字母和 `<>?` 之类的符号。
- 屏幕会自动滚动，光标会一闪一闪的（可爱吧）。
- 还内置了一个假的内存查看器，虽然不准但至少不蓝屏。

## 怎么编译？

哼，你不会连交叉编译工具链都没有吧？  
先装好 **i686-elf-gcc** 和 **QEMU**（不会装？那你是真的杂鱼呢~），  
然后双击 `build.bat` 就能生成 `fob.elf` 了。

运行命令：
```bash
qemu-system-x86_64 -kernel fob.elf
